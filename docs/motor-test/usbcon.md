# ファーム1.8.0 USBcon

通常画面と別のWebエントリ usbcon.html です。起動URLは http://127.0.0.1:18181/ouchi-colon/usbcon.html 。配布ビルドにも同名ファイルを生成します。既存の colon-motor-1.8.0 とBLE通信するWebアプリで、追加のファーム書込みは不要です。

1. PCで npm install 後、npm run dev -- --port 18181 --strictPort を起動し、上記ページをChrome / Edgeで開きます。
2. スーパーファミコン型USBコントローラーをPCへ挿し、ページをクリックしてコントローラーのボタンを1回押します。複数台の場合は使う機器を選びます。
3. 最初は左の接続欄でモックを接続し、入力番号とモーター表示を確認します。
4. 実機では接続先をAtomS3に切り替え、BLE接続します。電池3V・配線などは既存Motor Controlと同じ構成です。
5. 一度すべてのキーを離してから十字キーで操作します。上=前進、下=後進、左=左旋回、右=右旋回。各操作は100%・押している間だけ、最大500ms。上限後は離して押し直します。USBconの十字キーは90°自動旋回を開始しません。下部の既存キーボード・番号動作は従来の操作仕様です。
6. 十字キー以外のボタン・斜め入力は停止です。画面の緊急停止ボタンも利用できます。停止・切断・画面非表示・フォーカス喪失後は、入力を離すまで再開しません。

USB製品のボタン番号は共通ではありません。標準マッピングはbuttons12/13/14/15、非標準の初期値はaxes1-/1+/0-/0+です。「割当を変更」で各方向のボタンを押し、全キーを離した後に該当方向を入力すると変更できます。割当中は駆動しません。重複割当は拒否し、割当は機器名・接続インデックス別にこのブラウザへ保存します。「標準の割当に戻す」で保存値を消します。入力表示でGamepad APIに出ている番号を確認できます。Gamepad APIへ入力を公開しないUSBアダプターは操作できません。

コントローラー→USB→PCブラウザ→BLE→AtomS3です。AtomS3へコントローラーを直接USB接続する機能、USB経由の走行通信は今回の範囲外です。PCでlocalhostまたはHTTPSを使用します。[Gamepad APIの接続・入力仕様（MDN）](https://developer.mozilla.org/en-US/docs/Web/API/Gamepad_API/Using_the_Gamepad_API) に基づいて実装しています。

本体側の350ms心拍切れ停止・起動停止・500msの手動操作上限は維持します。USB抜去やブラウザ停止要求が遅れても本体側の上限で停止します。押し続けての指令更新による連続走行は実装していません。
