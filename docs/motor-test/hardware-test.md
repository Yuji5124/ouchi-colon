# 実機試験の順序（未実施）

2026-11-05：未測定1.5V想定の片側試験は[本体単独1.2の別手順](single-motor-test.md)で扱います。標準1.1の信号試験の後、電源・部品を確認できたら、ラジコン試験版1.3.0でPhase 6に進めます。

この文書は確認用です。この作業で実機の書込み・モーター通電はしていません。配線変更はUSB・VMとも電源を切ってから。緊急時にVMを物理的に遮断できることを先に確認してください。

## Phase 1：調査

1. AtomS3 C123、AE-DRV8835-S、70227付属純正モーター、SMARTCOBYの現物型番、DC-DCの正確な仕様を記録。
2. 実機に入っている既存ファームウェアのソース・版・復元方法を確保。既存BLEやロボット機能がある場合、今回の独立ターゲットで上書きしない。
3. GPIO5〜8、LEDCチャンネル0〜3 / 共有タイマーの占有を確認。

## Phase 2：モック

1. `?motor=1` → モック接続 → 安全確認 → 許可。
2. 左正転、停止、右逆転をそれぞれ再許可して確認。左右独立であることをログで確認。
3. 最大パルス、モックHB停止、通信断、再起動、緊急停止・解除を確認。解除・再接続後に自動始動しないこと。
4. 診断ログをJSON / CSVへ出力。情報源がmockであること。

## Phase 3：ATOM単体

**この段階の書込みもユーザーによる対象・復元方法の確認後に限ります。** モーター電池 / VM配線を物理的に外し、外付け回路も一旦外します。

1. `pio run` のビルド結果と通電ロック=0を確認。対象機器と既存ファーム復元を確認してから、ユーザー自身の操作・承認で書込み。
2. USBでATOMだけを給電。G5〜8の起動時LOWを測定。初期化前の浮きやブート中の波形も測定し、外付けプルダウンの効果を確認。
3. 対応ブラウザで専用Motor Test BLEへ接続し、firmware、bootId、稼働時間、起動回数、再起動理由を確認。
4. Phase 3・信号のみ・VM外し確認後、許可。左右各パルスのGPIO波形を測定。
5. タブ非表示、指離し、PC通信切断でLOWへ戻るか確認。ブラウザの停止表示だけを合格判定にしない。
6. 通信を完全に止めても、最大パルス500ms以内＋5msタスク周期と測定誤差の範囲でLOWになることを測定。既定200msでまず確認。
7. リセット・再接続で勝手に始動しないこと。GPIO安全が合わなければ以後中止。

## Phase 4：DRV8835信号

VMとモーターは未接続のままです。電源を切って、[配線表](hardware.md)の論理系だけ接続します。

1. MODE=GND、VCC=3.3V、共通GNDと各端子の向きを確認。
2. USB投入・抜差し・リセット時に全入力LOW、誤ったHIGHがないか測定。
3. 単体正転 / 逆転時はIN1 / IN2の片方だけがPWMになること、停止時00になることを確認。
4. 方向反転前に停止・再許可が必要なことを確認。

## Phase 5：電気的適合を確認した後のモーター単体

**現状は開始不可です。配布ファームは通電禁止です。** 少なくとも次を測定・確認するまで進みません。

- DC-DCの1.5V設定に対する、無負荷 / 負荷時 / 起動時 / USB抜差し時のVM実測とオーバーシュート。
- DRV8835-S基板で1.5Vを採用できる根拠と熱・電圧降下・保護動作。
- モーター許容電圧と始動 / 拘束電流、DC-DC電流容量、電源保護、配線極性、逆流・逆起電力対策。
- DC-DC入力GND / 出力GND / USBの関係、物理遮断手段。

不適合・不明の場合は通電試験を行いません。代替は「1.5V入力と必要な始動電流をメーカーが保証するドライバ / モジュールを選定し直す」、または「使用電圧・電流がドライバ / 電源と一致するモーターを含む構成へ再設計する」です。具体型番は部品の電流値が確定してから選びます。モーターへの印加電圧を3V・5Vへ上げたり、PWMで平均を下げるだけで解決しません。

適合確認が完了したときだけ、記録をレビューして別の通電許可ビルドを用意します。キャタピラを浮かせ、最小限の短いパルスで左だけ、次に右だけ。始動電流・発熱・電圧降下を測定し、異常ならVM物理遮断。

## Phase 6：浮かせた走行試験

1. 先にMotor Testで「モックを接続」→「1回の操作を許可」。十字キーの4方向を押し続け、離した後に左右0%になることを確認します。
2. VMと外付け回路を外し、USB欄で「ラジコン試験 1.3.0」を選んでバックアップ・書込み・再起動を行います。AtomS3液晶に「ラジコン試験」と出ます。
3. VMを外したまま実機BLEで `Colon-Motor-Test` に接続し、`colon-motor-1.3.0` と左右0%を確認します。まずPhase 4と「信号のみ試験」で方向・停止を確認できます。
4. Phase 5の確認を済ませ、VM–GND間の実測電圧を左側の安全確認欄に入力します。試験上限は1.5Vです。表示消灯後も電源が維持されること、両輪の始動時に必要な電流を電源・基板・配線が扱えることを確認します。値は手入力で、本体にはVMを測るセンサーがありません。
5. キャタピラを浮かせ、Phase 6を選択。「信号のみ試験」のチェックを外し、実機の4項目を確認します。「1回の操作を許可」→前進・後退・旋回を1回ずつ。最初に左右の向きを個別に確認し、必要なら反転を設定します。
6. 指離し、最大時間、緊急停止、通信断で出力が停止することを確認します。床置き試験へは、左右の停止と電源の適合性を確認できてから進みます。

走行試験は1回の許可につき最大500ms、各側75%以下、PWM 1kHz固定です。停止後に再許可します。通電走行中の保存パターン実行はファーム側で拒否します。電源適合フラグは未確認のままです。

出力指令が出ても回らない場合は、VMが維持されているか、ドライバVCC、MODEと共通GND、信号線、モーター出力端子の順に確認します。タミヤ70227は単3電池1本の構成です。AE-DRV8835-Sの仕様範囲内でも、低いVMでは負荷を十分に駆動できない場合があります。[タミヤ製品仕様](https://www.tamiya.com/japan/products/70227/index.html) · [秋月電子モジュール仕様](https://akizukidenshi.com/goodsaffix/AE-DRV8835-S_20210526.pdf) · [TIデータシート §9.2](https://www.ti.com/lit/ds/symlink/drv8835.pdf)

## 本体ボタンを使う起動試験 1.4.0

部品番号19407304のモーターをFA-130RA-2270相当と仮定した、左1個の短時間試験です。両者が同一という確認は取れていません。マブチの使用電圧範囲は1.5〜3.0V、1.5Vでの拘束電流は2.2Aです。DRV8835は1回路最大1.5Aなので、VM電源に1.0A以下の外部電流制限を用意します。PWM 50%は速度指令で、電流制限の代わりには使いません。[マブチの仕様](https://product.mabuchi-motor.co.jp/detail.html?id=9) · [TIの仕様](https://www.ti.com/lit/ds/symlink/drv8835.pdf)

1. VM–GND間を測り、1.5〜3.0Vの実測値を左側の安全確認欄に入力します。実測値と外部電流制限・車体準備の確認がある場合に、画面からこの版を書き込めます。
2. USBとモーター電源を切り、VM・外付け回路を外します。USB欄で「起動試験 1.4.0」を選び、バックアップと書込みを行います。
3. VMを外したまま、普通の給電では液晶に「起動試験なし」と出ることを確認します。USBをいったん抜き、液晶の正面を押したまま給電して「起動出力を送信」が出ることを確認します。液晶表示は出力指令の結果です。回転やVMを実測した表示ではありません。
4. VMとUSBを切り、電流制限付きの電源と左モーターだけをつなぎ、キャタピラを浮かせます。正面ボタンを押したままUSB給電すると、左の正転指令を1回だけ出します。ボタンを離すか100msのパルス終了で停止します。

正面ボタン（G41）はダウンロード用の側面リセットとは別です。波形はハードウェアで100msに制限し、起動後に正面ボタンを押しても再始動しません。BLEは状態確認用で、BLEからの駆動指令は拒否します。通常のラジコン操作に戻すには1.3.0を書き戻します。電圧と電流制限の確認は手作業です。[AtomS3の回路図とピン情報](https://docs.m5stack.com/en/core/AtomS3)

## 左右同時の起動試験 1.4.2

USB欄で「起動試験 1.4.2（本体ボタン／両側100%・2秒）」を選びます。VM–GND間の実測1.5〜3.0V、左右が共用するVM電源全体の外部電流制限1.0A以下、キャタピラを浮かせる条件は上記と共通です。単3電池2本を直接つなぐ構成では、外部電流制限の条件を満たしません。

1. VMと外付け回路を外して書き込みます。VMを外したまま、通常の給電で「起動試験なし」、正面ボタンを押したままUSBで給電すると「起動出力を送信」と表示されることを確認します。
2. 信号を計測できる場合は、G5/AIN1とG7/BIN1が同時に連続HIGH（デューティ比100%）になり、G6/AIN2とG8/BIN2がLOWのままであることを確認します。押し続けると200msの保持確認後に最大2秒出力し、途中で離すと両方が停止します。
3. 通電前にVMとUSBを切り、上記の電源条件を満たした状態で左右をつなぎます。キャタピラを浮かせて固定し、正面ボタンを押したままUSBで給電します。左右へ同時に論理正転を1回指令します。実際の回転方向はモーターの取付けと配線で確認します。

液晶表示は出力の結果を示します。回転やVMは実測されません。ハードウェアが最大2秒で出力を止め、起動後のボタン操作やBLEからの指令による再始動はありません。外部電流制限に達すると、100%の指令でもモーターが回り出さない場合があります。

## 走行プログラム 1.5.0

1. VMと外付け回路を外して「走行プログラム 1.5.0」をUSBで書き込み、普通に起動します。実機BLEで `Colon-Motor-Test` に接続し、1.5.0・左右0%を確認します。最初は「信号のみ試験」のままPhase 4で左右の出力と停止を確認します。
2. 「ラジコン操作」で1回の操作を許可し、PCの W（前進）、S（後進）、A（左旋回）、D（右旋回）を1つずつ押します。入力検知と左右の指令を画面で確認します。離す、画面を切り替える、通信が切れる、最大500msに達する、のいずれかで停止します。停止後は再許可が必要です。
3. 「Atomから読み込む」で既存設定を確認します。No. 1は前進、No. 2は後進で左右とも100%・1000ms固定です。No. 3〜5は右15°・30°・45°、No. 6〜8は左15°・30°・45°です。各旋回は25・50・75%から選び、時間を50〜500msで校正します。0msは未校正です。校正後は駆動許可を解除してAtomへ書き込みます。
4. 通電試験はキャタピラを浮かせ、VM実測1.5〜3.0V、共通VM電源全体の外部電流制限1.0A以下、物理遮断手段を確認してから行います。「信号のみ試験」を解除し、左側の安全確認を済ませます。出力が100%でも電流制限時は回転が始まらないことがあります。
5. 浮かせた状態で方向と停止を確認できたら、十分に空いた床で各旋回を1回ずつ実行し、実測した角度を見ながら時間を調整して保存します。

BLE上のパターン形式は `patternsVersion: 2` です。既存のPATTERNコマンドでNo. 1〜8を指定するときの値は0〜7です。旧形式の旋回時間と出力は、初回に旧NVS設定から引き継ぎます。新設定は別のNVSキーに保存されます。Colonの表情連動は初期OFFで、顔画面からの実機操作は信号試験です。

## Phase 7：SMARTCOBY診断

1. ATOM単体給電、DC-DC単体給電、両方同時給電を別ケースとして記録。
2. 各ケースで開始日時、無負荷待機時間、SMARTCOBY表示消灯までの時間を記録。
3. 表示が消えた後もUSB出力が維持されているか、対応する測定器で確認。「表示が消えた」だけでは「出力停止」にしない。
4. 通電適合確認済みの場合だけ、モーター駆動時のVMと電源状態を測定。未適合なら無負荷観察まで。
5. USB抜差し・再起動・長時間待機でbootId / 稼働時間 / 切断履歴がどう変わるか記録。
6. 発熱ありは試験中止。設定値、手動実測、未測定を区別してログ出力。

SMARTCOBYの現物型番が不明なため、低電流モードの操作方法や停止しきい値は未確定です。負荷抵抗追加などを場当たり的に行わず、型番の取扱説明書と測定で確認してください。
