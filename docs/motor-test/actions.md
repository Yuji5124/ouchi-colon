# Colon動作 A01〜A17 · 1.8.0

電池3V設定・出力100%・時間制御。角度指定はすべて、Atomに保存した左右共通の時間を使います。時間は角度の目安で、回転角センサーの測定値ではありません。

| 角度 | 右・左の共通初期時間 |
|---|---:|
| 15° | 2秒（2000ms） |
| 30° | 4秒（4000ms） |
| 45° | 6秒（6000ms） |
| 90° | 12秒（12000ms） |

片側の時間を編集すると、同じ角度のもう片側も更新されます。PC保存とAtomへの書込みは別操作です。実際の動作はAtomへ保存した値を読み込んで使います。

| 番号 | 動作 |
|---|---|
| A01 / A02 / A03 | 顔へ右15° / 30° / 45°（共通2 / 4 / 6秒） |
| A04 / A05 / A06 | 顔へ左15° / 30° / 45°（共通2 / 4 / 6秒） |
| A07 | 顔・目の方向へ共通時間で旋回 → 前進2秒 → 指令停止応答確認 →「来たよ〜」 |
| A08 | 左旋回1秒 → 停止 → 右旋回1秒（時間指定の喜び動作） |
| A09 | 後進1秒 → 停止 → 前進1秒 |
| A10 | 後進0.5秒 → 停止1秒 → 前進0.5秒（各1回） |
| A11 / A12 | 右90° / 左90°（共通12秒） |
| A13 / A14 | ラジコン前 / 後ろ（50〜500ms） |
| A15 / A16 | ラジコン左90° / 右90°。A12 / A11と同じ共通時間 |
| A17 | 停止要求。進行中・待機中の続き・連動を取り消す |

各指令の最後は空転停止。連続動作の間には100ms以上、A10では初期1000msの停止を入れます。停止応答を確認した後に待機するため、BLE通信時間の分だけ実際の停止間隔が延びる場合があります。A10の間隔は画面で100〜2000msに変更できます。旧ブラウザ設定の200msは新しい設定形式colon-actions-v2への移行時に1000msへ変更し、顔方向のしきい値などは維持します。

## 試す順番

1. [Motor Control](http://127.0.0.1:18181/ouchi-colon/?motor=1)をCtrl+F5で更新します。「モックを接続」で、右・左それぞれ2000/4000/6000/12000msの表示と停止を確認します。
2. 実機はVMと外付け回路を外し、USB欄から走行プログラム1.8.0を書き込みます。通常起動後、BLEのColon-Motor-Testへ接続し、本体版1.8.0を確認します。実装作業では書込み・通電を代行していません。
3. 旧v3/v4/v5の旋回値は、1.8.0への更新時に共通2/4/6/12秒へ置き換わります。前後進は各1秒です。新しく保存したv6の共通値は再起動後も保持します。
4. 「Atomから読み込む」で確認し、必要なら時間を調整して「Atomへパターンを書き込む」。No.1/2=前進/後進、No.3〜5=右15/30/45°、No.6〜8=左15/30/45°、No.9/10=右/左90°です。
5. [配線](hardware.md)を確認し、キャタピラを浮かせて前後→左右→複合動作→停止・切断の順に試します。右はA−100/B＋100、左はA＋100/B−100。配線変更は電源を切ります。
6. W/Sは押している間だけ、離すか上限時間で停止。A/Dと左右矢印は1回で左/右90°を実行し、初期は12秒です。途中で止めるには停止または緊急停止を押します。キーリピートは再始動にしません。入力欄の編集中は方向キーを受け付けません。
7. [Colon連動画面](http://127.0.0.1:18181/ouchi-colon/?debug=1&motorLink=1)内で再接続し、言葉・表情や顔方向をONにします。カメラとマイクは既存の開始ボタンで起動します。初期は連動OFFで、停止・画面非表示・切断でOFFへ戻ります。

## 保存・入力・停止の範囲

AtomのNVSに保存するのは基本動作10個の共通校正値（形式6）。A01〜A17の順序と発話は、前面のブラウザが管理します。ブラウザを閉じたままの単独実行には対応していません。別ブラウザでもAtomの共通値を読み込んで実行します。

顔方向は既存の目の左右の値と顔の見かけの幅を使用し、実距離は取得しません。顔幅/画面幅が0.15未満なら左右のずれを1.25倍、0.35超なら0.75倍。正面0.12、30°境界0.35、45°境界0.65を初期値にし、3回連続の同じ方向と動作後2秒の間隔で選びます。A07は顔が未取得・1秒以上古い状態なら開始せず、移動中の顔消失でも中断します。

言葉連動は「こっちきて」「右向いて」「左向いて」「止まれ」の明確な入力に対応。ラジコンの言葉モードでは「前」「後ろ」「左」「右」がA13〜A16になります。HAPPY表情にはA08またはA09、内容不明のfallbackにはA10を割り当てます。「右向いてって言ったらどうなる？」などの会話では動きません。到着音声はColonの選択済み音声、テスト画面はブラウザ音声です。音声を利用できない場合はA07を開始しません。

本体が独立して心拍350ms・最大12000ms・切替前100ms停止を監視します。停止・緊急停止・非表示・フォーカス喪失・切断・再起動で残りを取り消し、復帰後も自動再始動しません。連動OFFでも接続中の「止まれ」は受け付けます。12秒動作の途中でも通信断停止は350msです。

「停止を要求」は送信要求、「停止指令を確認」は本体の指令値0の応答を確認した表示です。電圧・回転・軸の固定を測定した表示ではありません。ログの「操作設定の上限ms」と「実行パルスms（本体指令）」は別項目。停止中の実行パルスは空欄（JSONはnull）です。

PC Chrome / EdgeとAndroid Chromeなどで実機BLEを利用できます。iPhone Safariは実機BLE・USB書込みに対応せず、モックを使用します。電池3Vはユーザー設定で、実電圧・電流・発熱・旋回角は未測定です。物理的に電池を遮断できる状態で試験します。
