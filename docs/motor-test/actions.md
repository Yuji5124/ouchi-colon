# Colon動作 A01〜A17 · 1.7.0

電池3V、出力100%を前提に、時間で動きを調整します。操作ごとの許可ボタン・電源診断メモはありません。接続・起動・再接続だけでは動きません。

| 番号 | 呼び出し | 動作 |
|---|---|---|
| A01 | 顔へ右15° | 右15°の校正時間 |
| A02 | 顔へ右30° | 右30°の校正時間 |
| A03 | 顔へ右45° | 右45°の校正時間 |
| A04 | 顔へ左15° | 左15°の校正時間 |
| A05 | 顔へ左30° | 左30°の校正時間 |
| A06 | 顔へ左45° | 左45°の校正時間 |
| A07 | こっちきて | 最新の顔・視線方向へ旋回 → 前進2秒 → 停止 →「来たよ〜」 |
| A08 | うれしい1 | 左旋回1秒 → 停止 → 右旋回1秒 |
| A09 | うれしい2 | 後進1秒 → 停止 → 前進1秒 |
| A10 | よくわからない | 後進0.5秒×3 → 前進0.5秒×3、各動作間で0.2秒停止 |
| A11 | 右向いて | 右90°の校正時間 |
| A12 | 左向いて | 左90°の校正時間 |
| A13 | ラジコン前 | 100%前進、設定時間（50〜500ms） |
| A14 | ラジコン後ろ | 100%後進、設定時間（50〜500ms） |
| A15 | ラジコン左 | A12と同じ左90° |
| A16 | ラジコン右 | A11と同じ右90° |
| A17 | 止まれ | 出力・待機中の続き・自動連動を取り消す |

最後はすべて空転停止です。A08・A09の動作間にも100ms以上の停止を挟みます。A10の初期停止間隔はユーザー指定の200msで、画面から100〜2000msへ変更できます。BLE応答の待ち時間は動作間隔に加わる場合があります。

## 試す順番

1. `http://127.0.0.1:18181/ouchi-colon/?motor=1` を開き、「モックを接続」。17個の番号付きボタンで動作・停止を確認します。
2. 「動作パターン」のNo. 3〜8（左右15・30・45°）とNo. 9・10（右90・左90°）の時間を入力し、Atomへ保存します。未校正の0msでは旋回を開始しません。
3. 実機ではVMと外付け回路を外し、USB欄から1.7.0を書き込みます。書込み後、通常起動してBLEの`Colon-Motor-Test`へ接続します。書込み・モーター通電はユーザーが行います。
4. 配線はG5→AIN1、G6→AIN2、G7→BIN1、G8→BIN2、3V3→VCC、GND→MODE/GND、電池＋→VM、電池−→共通GNDです。配線変更は電源を切って行います。
5. キャタピラを浮かせ、前後→左右→角度校正→複数動作→停止の順に確認します。右はA−100/B＋100、左はA＋100/B−100です。取り付けが異なる場合は各出力の方向反転で調整します。
6. W/Sは押している間だけ前後進し、離すか最大時間で停止。A/Dは押した時に1回だけ左/右90°旋回します。キーを離しても90°旋回は設定時間まで続きます。中央停止または緊急停止で中断できます。矢印キーも同じです。入力欄の編集中は方向キーを受け付けません。
7. Colonの顔画面 `?debug=1&motorLink=1` に移動して同じ画面内で再接続。「言葉・うれしい・よくわからないを連動する」をONにします。カメラ・マイクは既存の開始ボタンで起動します。別タブを非表示にしての実機制御は行いません。

No. 1=前進100%・1秒、No. 2=後進100%・1秒は従来どおりです。A番号はColonの複合動作、No.番号はAtom内の基本校正値です。

## 顔・言葉・音声の範囲

顔の方向へ自動で向く機能は別のスイッチで初期OFF。顔の左右のずれを0〜1として、正面範囲0.12、30°の境界0.35、45°の境界0.65を初期値にします。顔幅/カメラ画像幅が0.15未満ならずれを1.25倍、0.35超なら0.75倍します。3回連続した同じ方向と、動作後2秒の間隔を条件に1回旋回します。視線の左右は既存の目の方向・カメラ反転設定に合わせています。

これは**顔の見かけの大きさによる選択で、実距離の測定ではありません**。検出されない顔・1秒以上更新されていない顔ではA07を開始しません。A07の移動中に顔を見失った場合も中断します。追尾は対象との衝突を検出しません。モックの仮の顔入力はモック専用で実機へは適用しません。

連動ON時、既存のHAPPY表情イベントにA08またはA09を割り当て、会話が内容不明のfallbackを返した時にA10を実行します。音声認識または会話入力欄で「こっちきて」「右向いて」「左向いて」「止まれ」と明確に入力された場合だけ各動作へ振り分けます。「右向いてって言ったらどうなる？」などの会話には反応しません。ラジコンの言葉モードをONにすると、「前」「後ろ」「左」「右」をA13〜A16へ結び付けます。初期OFFで、停止・切断時にもOFFになります。画面の「言葉で試す」も同じ判定です。

到着音声は顔画面の選択済み音声を使います。テスト画面だけの場合はブラウザの日本語音声合成です。音声が利用できない状態ではA07を開始しません。前進終了は本体の指令停止応答で判断し、実際の移動距離・目的地到着は測定していません。発話中は既存のマイク抑制を使い、音声認識が対応しない端末では入力欄を利用します。顔・音声の本文は動作ログへ保存しません。

## 保存と通信

- AtomのNVSへ保存：基本動作10個の出力・校正時間。パターン形式5、`patterns-v5`。旧v4の8個を引き継ぎ、90°は0msで追加。v3からは実機で逆だった左右の時間を入れ替えて移行します。
- ブラウザへ保存：A10の停止間隔・顔方向の境界・HAPPYの選択。連動ON状態と実行途中の続きは保存しません。「動作一覧をJSONで保存」で連携用の番号一覧を出力できます。
- A01〜A17の順序と発話はブラウザで管理し、実行時にAtomの校正値を読み込みます。17個の複合動作全体がAtomへ書き込まれる仕様ではありません。ブラウザを閉じた状態での単独実行は未対応です。
- 既存のBLEサービスと20byteフレームを再利用。従来の直接操作mode4は50〜500ms、新しい動作ステップmode5は50〜2000ms。1.7.0以外にはmode5を送りません。
- 独立した本体タスクが心拍350ms、各ステップ最大2000ms、方向変更前100ms停止を監視。ブラウザ停止・緊急停止・非表示・フォーカス喪失・切断・再起動で続きと自動連動を取り消し、復帰しても自動再始動しません。

## 測定上の限界

電池3Vはユーザー指定で、VM実測値とは扱いません。モーター同定・3V印加時の発熱・始動/拘束電流、配線や電池の電流容量は実機検証が必要です。100%出力は電圧を下げません。停止はLOW/LOWによる空転停止で、軸の即時固定や障害物回避を保証しません。物理的に電池を切り離せる状態で試験してください。
