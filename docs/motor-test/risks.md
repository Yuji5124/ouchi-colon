# 未解決リスク / 受入れ条件

ユーザー指定により、1.5V想定・未測定の[本体単独試験1.2](single-motor-test.md)を別途用意しました。電源適合を保証する機能ではなく、以下の未解決リスクは残ります。物理スイッチ、単体75%以下・100ms上限は過電圧対策の代わりにはなりません。

| 項目 | 現状 | 次の確認 |
|---|---|---|
| DC-DC出力 | 設定1.5Vのみ、実測なし | 無負荷・負荷時・過渡の実測 |
| VI-87基板 | 正確な型番・回路不明、写真未提供 | 入出力仕様、GND導通、容量、逆流条件 |
| DRV8835-Sの1.5V | 資料の欄で0V / 2V下限が混在、完成回路未保証 | 供給元確認と実測・電圧降下・熱検証 |
| タミヤ純正モーター | 70227付属、単3×1の製品構成 | モーター型番、許容最大電圧、始動 / 拘束電流 |
| SMARTCOBY消灯 | USB出力停止か不明 | 表示消灯後の出力を実測 |
| SMARTCOBY型番 | 30W製品に複数仕様あり | 現物ラベル、2出力同時利用、低負荷条件 |
| GPIO起動波形 | コード上LOW初期化、現物未測定 | リセット・電源順序・外付けプルダウン |
| 停止 | ソフト停止と独立タスクはコード試験済み | 実GPIO波形と軸の惰性を測定 |
| 物理遮断 | UIで確認項目として提示、現物未確認 | VMの物理スイッチ / 遮断手段 |
| 既存ATOMファーム | ソース・バイナリ未提供 | 復元方法とBLE / GPIO / PWMの競合確認 |
| BLE実機・iOS | 実機未接続。iPhone SafariはWeb Bluetooth不可 | 対応PC / Androidで信号のみ確認 |
| 認証・量産品質 | 近傍BLEのテストサービス、認証・冗長遮断なし | 実用運転前に認証・ハードインターロック設計 |
| USB実機書込み | 実装と疑似ローダー試験、同梱ビルド済み。実機未実施 | バックアップ・復元確認、実機チップ確認、書込みと読戻し |
| 旋回角度 | 角度フィードバックなし。初期0msで禁止 | 電源適合後、条件を記録して時間校正。精度保証なし |
| 表情連動 | 初期OFF、許可1回につき1動作。実機未実施 | 予期しない表情変化を含む割当確認、実機停止検証 |

UIの安全チェックは自己申告であり、測定センサーの代わりではありません。ビルド成功とコードテスト成功は、配線の安全やモーター通電試験合格を意味しません。

最初に進められる実機作業は **VMを外したAtomS3単体 / 信号試験** です。書込みは対象機器・既存ファームの復元方法とユーザーの明示承認を確認した後です。現在の1.5V構成で通電可能という判断はしていません。
