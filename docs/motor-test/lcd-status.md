# AtomS3本体の接続・停止表示

標準信号版1.1.1／本体単独版1.2.1から、C123の128×128液晶に状態を日本語で表示します。給電とBLE接続は区別します。USBを挿しただけではブラウザとの通信は開始しません。

| 本体の表示 | 意味 |
| --- | --- |
| 起動中 | GPIO停止初期化後、BLE起動処理中 |
| 接続待ち | 本体は動作中、BLE未接続 |
| 接続済み | BLE接続中、駆動許可なし |
| 駆動許可 | 明示確認で1回の試験を許可 |
| 駆動中 | モーター制御の指令値が0以外 |
| 緊急停止 | 停止ラッチ中。解除しても再許可は別操作 |
| 初期化失敗 | GPIO初期化または安全タスク作成失敗 |

上部に版番号、右上に1秒周期の動作印、下部に指令値・試験種別・VM未測定・稼働時間を表示します。出力値は指令であり、回転・電圧・電流の実測ではありません。LCDが固まっていても停止の証拠にはなりません。

Webの「接続・停止状態」に「本体液晶」を追加しました。「表示処理起動済み」は初期化と画面タスク作成の成功通知で、実際に見えていることの測定ではありません。旧版は「この版は液晶の状態通知なし」、未接続は「未取得」です。切断後の最終HB時刻は「切断前」と明示します。ブラウザは通信せずに本体への給電有無を判定できません。

## 更新と確認

1. モーター電源VMと外付け回路を外します。
2. PC Chrome / EdgeのMotor Testで、用途に合わせて「信号試験1.1.1」または「本体単独1.2.1」を選びます。
3. 既存内容のバックアップ・復元方法を確認し、USB接続・書込みをユーザー操作で行います。全面消去は行いません。
4. 再起動後、給電だけで本体に「接続待ち」が出るか確認します。
5. USBを切断してBLEの「Colon-Motor-Test」を選び、本体とWeb両方の接続表示を確認します。BLE切断で本体が「接続待ち」に戻ることも確認します。
6. VMを外したまま停止・緊急停止の表示を確認します。給電や再接続だけで駆動許可は復活しません。

本体単独版の片側100ms・75%以下・1kHz、未測定1.5V想定、パターン実行禁止という制限は変更していません。LCD追加によって電源適合を確認したことにはなりません。表情連動は後工程のままです。

## 実装・GPIO

[M5Stack公式AtomS3資料](https://docs.m5stack.com/en/core/AtomS3)とM5GFXのC123/GC9107構成を参照しました。MOSI=G21、SCLK=G17、CS=G15、DC=G33、RESET=G34、バックライト=G16。モーターのG5/G6/G7/G8は変更していません。C123/GC9107を明示設定し、別機種を探すGPIO自動検出は行いません。バックライトはデジタルHIGH固定で、モーターPWMのLEDCチャンネル0〜3を消費しません。異なる液晶・AtomS3 Lite/S3R等は対象外です。

安全タスクはcore1・優先度5・5ms周期、LCDはcore0・優先度1です。共有状態のコピーだけを短い排他区間で受け渡し、描画/SPIはその外で行います。GPIOをLOWにしてから液晶を初期化します。液晶処理からモーター状態を書き換えません。液晶用8bitスプライトに約16KB、専用タスクに約6KBの実行時メモリを使います。

M5GFX 0.2.36（MIT）と日本語efontを同梱ビルドに使用しています。[M5GFXライセンス](licenses/M5GFX-MIT.txt) / [efontライセンス](licenses/efont-COPYRIGHT.txt)。

## 検証範囲

自動検証は表示状態の遷移、停止理由、再接続での待機、優先表示、GPIO分離、描画用コピーが制御を変更しないこと、旧ファームとの状態通知互換、配布バイナリの版・制限・ハッシュです。ビルドとコード上の検証までで、本体の表示・文字位置・SPI動作・メモリ余裕・BLEと描画の同時動作は実機未検証です。開発作業から書込み・モーター通電は実施していません。

Windowsでビルドパスが長い場合は、PlatformIOの `PLATFORMIO_BUILD_DIR` と `PLATFORMIO_LIBDEPS_DIR` に短い絶対パスを指定します。配布生成は同じ `PLATFORMIO_BUILD_DIR` と `PLATFORMIO_CORE_DIR` を設定し、`node scripts/package-motor-firmware.mjs`（標準）、`node scripts/package-motor-firmware.mjs --single`（単独）を実行します。
