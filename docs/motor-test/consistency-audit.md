## 見つかった食い違いと修正

1. USB手順書に旧1.1・12パターン・都度許可が現行手順として残っていました。現行1.7.0・10個の基本校正値に修正し、旧版は折り畳んだ履歴へ移しました。本体液晶の現行版表示も1.7.0へ統一しました。
2. ログの操作設定500msと、A07などの実行指令2000msの区別が不明確でした。CSVへ「操作設定の上限ms」と「実行パルスms（本体指令）」を分けて記録し、停止中の実行パルスは空欄にしました。JSONではactivePulseMsが停止中nullになります。3V想定・実測なしも明示して保持します。
3. W/Sや基本パターンで出力している間も、A動作パネルが「停止中」と表示していました。実行中・他の操作による出力・通信処理・指令停止確認を分けました。A17も応答前に「停止しました」と断定せず「停止を要求しました」に修正しました。
4. 1.6.1では使えない90°ボタンが押せる状態でした。ボタンを無効にし、W/Sの前後進は利用可能、90°・17動作には1.7.0への更新が必要と表示します。更新先を1.6.0へ戻す古いエラー文も修正しました。
5. 停止直前に受け付け、まだ開始していない音声指示が停止後に実行される余地がありました。受け付けた時点の世代と接続先を照合し、停止・切断・モード変更後の指示を取り消します。動作間の本体STOP応答でも残りを再開しません。連動OFFでも、接続中の「止まれ」を受け付けます。
6. モックの仮の顔位置が切断直後に残る状態でした。接続先変更・切断・再起動で消去し、実機側へ引き継ぎません。モックの起動状態・再起動後の稼働時間・ARM重複拒否・ゼロ駆動拒否・旧RC ARMも本体に合わせました。
7. 新しいA動作のテストがtest:motorの対象から漏れていました。motor-*.test.tsへ統一し、基本パターンをPC保存する際も現行の10個だけを保存します。
