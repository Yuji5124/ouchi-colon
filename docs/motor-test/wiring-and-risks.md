# GPIO・配線と未解決リスク

2026-11-03。対象は通常の **AtomS3（C123）**。AtomS3R／Lite等へ流用する場合は改めてピンを照合します。

## コード上で確定した割当

| AE-DRV8835-Sの表示 | モジュール端子番号 | 接続 |
|---|---:|---|
| AIN1 | 10 | AtomS3 G5 |
| AIN2 | 9 | AtomS3 G6 |
| BIN1 | 8 | AtomS3 G7 |
| BIN2 | 7 | AtomS3 G8 |
| VCC | 12 | AtomS3 3V3（3.3V） |
| GND | 6 | 共通GND |
| MODE | 11 | GND（GPIOは使わない） |
| VM | 1 | DC-DC OUT+、物理スイッチを介す |
| AOUT1 / AOUT2 | 2 / 3 | 左モーターの2本 |
| BOUT1 / BOUT2 | 4 / 5 | 右モーターの2本 |
| DC-DC OUT− | — | 共通GND（構成確認後） |

端子番号は秋月資料の表によります。現物の向き・印字を確認してください。Groveの5VをVCCの3V3と取り違えないでください。モーターに3V／5Vを直接加える配線は行いません。

M5Stack公式ではG5／6／7／8が公開GPIOです。LCDはG21／17／15／33／34／16、IMUはG38／39を使用し、この4本とは競合しません。既存リポジトリにも使用箇所はありませんでした。GPIOの重複と予約外ピンはモック・C++の双方で検査します。外付け部品が実際につながっているかはソフトで検出できません。

MODE=LOWの制御は00=空転、10=一方向、01=逆方向、11=ブレーキ。本実装のSTOPは00で、11によるブレーキは使用しません。左／右の前進方向は鏡像配置を考慮してソフト設定で反転できます。

## 1.5Vの扱い

- TI Rev.Hの推奨動作条件はVM=0〜11V、VCC=2〜7V。
- 秋月の同一資料には、概要でモーター電源2〜11V、動作条件表で0〜11Vの記載があります。
- したがって「ICが必ず2V未満で動かない」とも、「手元の基板・モーター一式が1.5Vで確実に動く」とも判定しません。
- ユーザー設定の1.5Vは実測値ではありません。DC-DCの入力、出力、負荷時変動、極性、電流容量、モーターの始動／拘束電流は未確認です。
- PWMは速度制御であり、過電圧の代替保護にはなりません。

現状はモーター駆動の適合未確認です。秋月への1.5V運用条件の確認、現物モーターの定格確認、電流制限可能な測定用電源での評価が先です。適合を確認できなければ、基板全体として低VM対応が明記されたドライバーと定格内の電源構成に変更する案を検討します。電圧を3Vや5Vへ上げてPWMだけで対処する案は採用しません。

## 未解決一覧

| 項目 | 状態／次の確認 |
|---|---|
| DC-DC設定1.5Vと実測の一致 | 未測定。VM端子位置でも実測する |
| VI-87の正確な回路・入出力GND関係 | 未確認。全電源OFFで導通／資料を確認し、接続を決める |
| SMARTCOBY表示消灯後のUSB出力 | 未測定。表示消灯と出力停止を分けて時刻を記録 |
| 低負荷停止、USB-C交渉、接触等の直接原因 | 未判定。表示だけで原因を決めない。正確な型番と取扱説明書も確認 |
| 2出力同時使用時の給電変化 | 未確認。各単独→両方の順に測定 |
| タミヤ70227付属モーターの個別定格・拘束電流 | 公開製品ページだけでは確定できない。現物／説明書／測定で確認 |
| 放熱・電源／配線の許容電流 | 未検証。ICの1.5A表記だけで基板と配線の連続運用を保証しない |
| リセット／起動中の出力、逆転時の過渡、ノイズ | 未測定。モーター電源を切った信号試験から開始 |
| 車体の空転停止距離・転倒 | 未検証。最初は浮かせ、低速・短パルス |
| 実物の物理スイッチ | 設置・定格未確認。ソフトの緊急停止とは別に用意 |

入力にIC内蔵の弱いプルダウンがあります。必要に応じて外付けプルダウン等を含む起動時の信号安定化を評価しますが、今回のソフトだけで実物の電気的安全性をPASSにはしません。
