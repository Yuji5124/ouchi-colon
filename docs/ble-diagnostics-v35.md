# Colon BLE v35：ラジコン・音声診断

2026-11-09。v34で「接続できるが方向ボタンを押しても動かない」「service-not-allowed」「TOHOKU未準備」の報告を受けた修正。実機の直接原因は状態読戻しで継続確認する。

- 押している方向ボタンは、許可消費・通信中でも有効に保ち、タッチ保持を妨げない。他の方向ボタンは無効のまま。指離し・キャンセル・非常停止で取り消す。
- MOVE前の予約・方向切替待ちで届く停止状態によって押下を解除しない。非常停止は準備中でも解除する。
- テストでstop-dwell拒否を確認。ブラウザー側の待ちを110msとし、タイマーが早く戻ったときも再判定する。本体の100ms安全条件は変更しない。
- 駆動許可の未確認項目、1回ごとの再許可、FW、起動ID、最終seq、左右出力、停止理由、通信エラーを表示。「駆動の診断情報」はコピー可能。発話や接続コードは含めない。
- 「マイク・音声の接続診断」で、マイク取得と音声認識とTOHOKU出力を分けて確認。マイク試験は取得したトラックをすぐ停止し、録音・送信しない。中止や時間切れの後に許可されたトラックも停止する。
- 音声認識の試験は保護者の別チェック後、1回だけ実行する。音声はブラウザーの認識サービスで処理される場合がある。認識本文は診断画面へ表示・永続保存しない。開始イベントのみで認識成功としない。
- service-not-allowedを「Safariのサイト設定」と一律に案内せず、ブラウザー側サービスの拒否として表示する。マイク試験成功で音声認識の利用許可を偽装しない。
- 診断開始時は駆動許可と会話を解除する。入力を停止してから出力を確認し、診断後は会話を自動再開しない。

既存BLE FW 1.8.0・100%出力・パルス上限・心拍350ms・非常停止・再接続時の自動再許可禁止を維持。新しいLLM・外部APIは追加しない。元の走行アプリやファームウェアは変更しない。

確認先： https://yuji5124.github.io/ouchi-colon/phone.html?v=35

「接続・操作」からラジコンを選び、各確認項目と「次の1回を許可」を確認して試す。動かない場合は「駆動の診断情報」を取得する。音声は同じパネルの診断を番号順に行う。

検証：回帰テスト、型チェック、本番ビルド、オフライン配信ファイル検証、git diff --check。iPhone 11/Bluefyの実際の許可プロンプト・音声認識・可聴出力・実機の駆動は別途検証が必要。ファームウェア書込み・実機駆動は実施していない。
