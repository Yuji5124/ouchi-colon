# OuchiColon 日本語会話辞書 500件

## 内容

- 500件の子どもの発話パターン
- 各発話に返答を5通りずつ、合計2,500件
- よく使う言い方・音声認識の表記ゆれを含む認識語句532件
- 10カテゴリ、各50パターン
- 日常のあいさつ、気持ち、生活の用事、家族・友だち、食べ物、遊び、自然、場所・天気、学び、会話の継続・訂正・終了

## 接続用フィールド

- `id`: 辞書項目の固定ID
- `category`: 分類
- `intent`: 会話上の意図
- `patterns`: 認識する日本語の発話
- `priority`: 優先度。医療・安全に関わる例は高く設定
- `safety_sensitive`: 既存の安全応答に渡すべき内容
- `session_action`: 会話中だけの話題更新、訂正、停止、終了の指示
- `topic_value`: 訂正後の話題（例:「電車じゃなくてお城」なら「お城」）
- `responses`: 5通りの返答。`continues`、`asks_question`、`next_topic`を含む

接続時は既存の安全・プライバシー応答を先に判定し、その後にこの辞書を使う想定です。発話履歴を保存せず、現在の話題だけを会話中メモリに置く構成にしています。返答は直前のものと重複しないよう選び、終了・「いやだ」には質問や催促を続けないでください。完全一致と文字正規化を基本とし、曖昧な音声認識をこの辞書だけで確定しない設計です。

今回の見直しでは、あいさつの時間帯違い、会話の訂正と題材の具体的な訂正、話題変更時に新しい題材を待つ動作、終了時の質問抑制、健康・秘密に関わる応答の安全ルートを整理しました。返答中の質問は約14%です。各項目の5返答が重複しないこと、認識語句が重複しないこと、質問フラグが本文と一致することを確認しています。

## 用意したファイル

- `OuchiColon_language_dictionary_500.json`: 接続用データ本体
- `generate_ouchicolon_language_dictionary.py`: 同じデータを再生成するスクリプト

この作業フォルダにはアプリ本体や会話エンジンのソースコードがないため、ランタイムへの登録はまだ行っていません。
