## 起動と確認

Node.js 22以降。依存関係が未導入なら `npm ci`。

```powershell
cd 'C:\Users\hp\Documents\ChatGPT\Ouchi Colon\Colon-Integrated-v32'
npm run build
$env:COLON_PUBLIC_ORIGIN = 'http://127.0.0.1:19181'
npm run integrated
```

http://127.0.0.1:19181/ouchi-colon/?debug=1 を開く。

1. 初期画面は顔と小さな「設定」「操作」。設定を開いてTOHOKU準備・音声有効化・保護者確認・会話開始を行う。
2. 「顔を見る」で詳細を畳む。会話を終了せず顔を表示する。
3. 「操作」→「モック」→「動作先に接続」。モードをラジコンにし、「次の1回を許可」→方向ボタンを押す。指を離すか上限時間で停止する。
4. 返答連動は、モードを「返答と連動」にし、次の1回を許可。許可した次の喜び・驚きの返答の実際の音声再生開始で短い片輪動作。通常・不明・安全・拒否・終了・就寝の返答は動作しない。動作は会話の入力文から直接決めず、会話エンジンのメタデータで決める。
5. 音声エラー・再生中断・終了・ページ非表示・フォーカス喪失・非常停止は停止要求。音声OFFの文字返答だけでは駆動しない。各動作後の再許可は自動化しない。
6. Notifは「PC表示サーバーを起動・接続」。初回起動に時間がかかるため、機器が見つからなければ少し待ち再接続。自動送信は明示的にONにし、1台を選ぶ。長い返答は128×128内で省略する。全文送信や画像編集はリンク先の既存エディターで行う。

初期状態はモック・動作OFF。設定や接続コード、会話本文は永続保存しない。元のエディターの「保存」は利用者が明示操作した表示プリセットをブラウザーに保存する既存機能。

## 携帯電話と横向き

横向きで詳細パネルを開くと、顔のCanvas領域を横に縮め、パネルと重ならないようにする。通常時は顔の下54pxとセーフエリアを操作用に確保。詳細診断は初期状態で折り畳む。非常停止は接続中に常時表示する。

この構成はPCがBluetooth/HTTP通信を仲介する。iPhone単独のWeb Bluetoothは使わない。携帯の音声認識・カメラには端末から信頼されるHTTPSが必要。PCでHTTPS配信するには信頼済み証明書を準備し、次を設定する。証明書検証の無効化やセキュリティ警告の回避は行わない。

```powershell
$env:COLON_PUBLIC_ORIGIN = 'https://PCの名前またはIP:19181'
$env:COLON_TLS_CERT = '証明書の絶対パス'
$env:COLON_TLS_KEY = '秘密鍵の絶対パス'
$env:COLON_PAIR_CODE = '自分で決めた12文字以上の接続コード'
npm run integrated
```

LAN公開はHTTPS・接続コードを必須にしている。初期起動は127.0.0.1だけに限定。秘密鍵やコードはGitに保存しない。GitHub PagesからPCのHTTPへ直接つなぐ構成ではない。

## 実機の成立条件

```text
ブラウザー → Colon統合サーバー → 既存Colon Atomアプリ :18180 → Notif :18080 → Bluetooth表示
                           → Motor Test API http://192.168.4.1 → モーター制御
```

Notif v5は文字・画像表示専用で、提供物にAtomS3ファームウェアのソースやモーターAPIがない。Motor Testは独自HTTPファームウェア。**現在、この2種類のファームウェアを同じ1台で同時に使うことはできない。** 2台を使う構成、または後日1台用ファームウェアを統合する必要がある。表示と走行の同時実機動作を保証しない。

実機接続先は固定IPだけ。任意URLをプロキシできない。Motor Testの診断専用ビルドは出力無効なので、接続できてもこのアプリは駆動許可を出さない。出力・電源検証済みフラグと、実測電圧・電流検討・配線・物理スイッチ・浮かせた状態の確認が必要。実測値を推測入力しない。

駆動は1回100/300/500ms、速度上限30%。押し続けても上限を延長せず、再駆動は手動許可。STOPは惰性停止。物理的な即時停止の保証はない。ファームウェア書き込み・モーター通電は今回実施していない。
