# Phase 3E.9「気分と生活リズム」

- 気分は子ども自身が話した内容から受け止める。疲れた・眠い・悲しい・こわい等には短く共感し、悲しさや怖さでは近くの保護者などの大人にも話すよう促す。
- 気分は既存の会話コンテキストの話題として会話中だけ参照する。発話本文や日々の記録を追加保存しない。
- 子どもが挨拶したときだけ、端末のローカル時刻を使い、5:00〜10:59は朝、11:00〜16:59は昼、17:00〜20:59は夕方、21:00〜4:59は夜の挨拶を返す。子どもが「おはよう」「こんばんは」と言った場合はその言葉を優先する。
- 挨拶や生活の予定を自動で始めたり、時計を使った催促・通知はしない。就寝の意思が示されたら遊びや物語を閉じ、質問を続けない。
- 朝・昼・夜は子どもの明示した挨拶や生活の発話も手がかりにする。時刻から気分、予定、家庭の習慣を推測しない。
